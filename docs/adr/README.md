# Contributor decisions

This folder is the log of accepted contributor decisions on this git. There are no numbered records until a public proposal is accepted.

The flow is in [CONTRIBUTING.md](../../CONTRIBUTING.md): issue with a proposal, discussion on this repo, the library developer writes the ADR here, then code.

DocC is how to use the library. These records are why an accepted change has the shape it has. A turned-down proposal is not recorded here: it becomes a Non-Goal in [PHILOSOPHY.md](../../PHILOSOPHY.md), naming the pillar it failed.
